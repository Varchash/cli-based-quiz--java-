
# CLI BASED QUIZ

## 1. Introduction

The Java Quiz Program is a console-based quiz program developed using Java. It allows users to answer multiple-choice questions and displays their final score.

## 2. Objective

- To develop a simple quiz program using Java.
- To understand classes and objects.
- To implement user input and answer validation.
- To calculate the final score.

## 3. Technologies Used

- Java
- JDK 8 or higher
- Scanner
- VS Code

## 4. Project Structure

```text
cli-based-quiz--java/
├── Ques.java
├── Quizalgo.java
├── Quizm.java
└── README.md
```

## 5. Description of Classes

### Ques.java

Stores quiz questions, options, and correct answers. It also displays questions and checks answers.

### Quizalgo.java

Contains quiz-related logic and operations.

### Quizm.java

Manages the quiz flow, takes user input, displays feedback, and calculates the final score.

## 6. Working

1. The application displays a welcome message.
2. Questions with four options are shown.
3. The user enters an answer.
4. The answer is checked.
5. Feedback is displayed.
6. The final score and percentage are shown.

## 7. Features

- Multiple-choice questions.
- Input validation.
- Instant feedback.
- Automatic score calculation.
- Multi-class Java structure.
- Easy to extend.

## 8. Result

The Java Quiz Application successfully runs in the console and allows users to answer questions while displaying their final score.

## 9. Conclusion

This project helped in understanding Java programming, object-oriented concepts, classes, objects, methods, and user input handling. It provides a simple and interactive quiz experience.
