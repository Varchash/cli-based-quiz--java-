
# Java Quiz Application

## 1. Problem Statement

Traditional quizzes require manual checking and score calculation. The Java Quiz Application solves this problem by providing a simple console-based quiz system that automatically checks answers and calculates the final score.

## 2. Scope of the Project

The project focuses on developing a Java-based multiple-choice quiz application. It allows users to answer questions, receive feedback, and view their final score. The application can be extended with more questions and features.

## 3. Target Users

- Students
- Teachers
- Quiz enthusiasts
- Beginners learning Java

## 4. High-Level Features

- Multiple-choice questions with four options.
- User input validation.
- Automatic answer checking.
- Instant feedback.
- Final score and percentage calculation.
- Multi-class object-oriented design.
- Easy to add new questions.
